- **Browser compatibility**: Mitigación → Feature detection y fallbacks
- **Performance**: Mitigación → Adaptive quality y connection management

## 📝 Notas de Desarrollo

### Decisiones de Diseño
- **Angular version**: 18.x para consistency con threejs-gamify-ui
- **WebRTC approach**: Native APIs con minimal dependencies
- **State management**: RxJS Observables siguiendo patrón existente
- **Styling**: CSS modules o styled-components para isolation

### Conventions
- **Naming**: PascalCase para componentes, camelCase para servicios
- **File structure**: Feature-based organization
- **Imports**: Relative imports dentro del módulo, absolute para external
- **Error handling**: Consistent error interfaces y logging

### Dependencies Strategy
- **Core deps**: Minimal para reduce bundle size
- **Dev deps**: Full tooling para development experience
- **Peer deps**: Angular y RxJS como peer dependencies
- **Optional deps**: TURN servers, advanced features como opcional
